ALUR KERJA

Bagaimana Kami Bekerja Sama?

Setiap anggota memiliki kontribusi spesifik untuk menciptakan hasil akhir yang solid.

1
Perencanaan

Membuat repository utama di GitHub dan menentukan pembagian tugas. Seluruh anggota kemudian melakukan clone repository ke komputer masing-masing.

2
Pengembangan Halaman

Setiap developer membuat branch baru khusus untuk fiturnya. Anggota mulai mengodekan halaman masing-masing (Profil, Anggota, Kontak) secara terpisah.

3
Push & Code Review

Setelah selesai, developer melakukan push ke branch mereka dan membuat Pull Request (PR). PM melakukan code review dan perbaikan jika diperlukan untuk memastikan kualitas kode.

4
Penggabungan & Sinkronisasi

Setelah kode disetujui, Project Manager melakukan merge ke branch utama (main). Seluruh anggota kemudian melakukan pull/sinkronisasi agar semua file di komputer lokal berada di versi terbaru.
